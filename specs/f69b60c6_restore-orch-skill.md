Public repos clone unauthenticated.
8. **VM tags**: `create RUN_ID TAG=''` — explicit arg wins; else derived from the roster's `app.repo` basename (lowercased, sanitized, ≤32 chars); vendored mode → `sssf`. Recorded in the run record as `tag=` and confirmed on the VM via `ls --json` (a missing tag is fatal in create). Tags exist for bulk identification/cleanup and name the APP, not the kernel.
9. **Teardown** (`teardown RUN_ID *FLAGS`, only flag `--no-harvest`): order is **artifacts → harvest → destroy → close**. Artifacts are a **gzipped delta-tar** (untracked-non-ignored + HEAD-modified files under `specs app_docs adws/adw_data/sssf.db run.log`, plus `<app.path>/<manifest>` in target mode; gitignored always-files included; empty delta skips the transfer) extracted to `.sandbox/runs/<run-id>-artifacts/`. Harvest failure **aborts before destroy** (VM left alive; message tells you to re-run or pass `--no-harvest`). Idempotent by construction; the run record is the one hard prerequisite. **No key revoke, no spend capture, no shred, no `reap`** — none of that exists here.
10. **Gate A** (`setup.just`): two modes. Target mode (`app.repo` set): factory HEAD must match `factory_sha`, target clone at `~/app/<path>` HEAD must match `commit_sha`, and only the **factory** tree must be clean. Vendored: HEAD matches `commit_sha` (and `factory_sha` when present). The configured `app.path`'s untracked-directory porcelain line (`?? <path>/`) is **filtered out** of the clean-tree assertion — custom app paths need **no .gitignore edit**. Other gates: **B** pi is current (== registry latest per `npm view`) and `pi --list-models` non-empty and not "No models available"; **C** every roster `model: provider/id` answers a ping **through pi** (`pi -p --no-tools --provider P --model M`); **D** a live pi call on the roster's `defaults.model` reports **non-zero cost** (pi's built-in rate table; `jq`, not python); **E** every roster provider's env var is set (map copied from pi's `getApiKeyEnvVars`; second copy lives in `sandbox_mount/host/roster_keys.sh`). C/D/E run as ONE remote script, exit codes 2/3/4 name the failure. Gate failure prints the `ssh` debug commands and leaves the VM alive.
11. **Run record** (`sandbox_mount/host/run_record.py`): closed schema `FIELDS = (run_id, vm_name, tag, https_url, session_id, commit_sha, factory_sha, ports, pid, created_at, closed_at)`; immutable: `run_id`, `created_at`. Writers: create → run_id/created_at/vm_name/https_url/tag/session_id; fill → factory_sha + commit_sha; execute → pid; observe → ports; teardown → closed_at. CLI: `new-id`, `create`, `get`, `set run_id field=value`, `list`, `close`. Records at `.sandbox/runs/<id>.json`.
12. **run layer** (`just/sandbox/run/mod.just`): `cmd RUN_ID +CMD` — `ssh <vm>.exe.xyz "cd app && <CMD>" < /dev/null`, `{{CMD}}` interpolated verbatim (you own the quoting; `< /dev/null` so a stdin-reading remote command can't hang the session). `agent RUN_ID PROMPT` — **pi**, not Claude Code: `pi -p --session-id $SID` over ssh with `app/.env` sourced; `--session-id` **creates-or-continues** (no first-turn sentinel file exists any more); synchronous; session_id minted once at create.
13. **execute**: `execute RUN_ID PROMPT CONFIG="" ADW="sdlc" *EXTRA` — CONFIG defaults to `/home/exedev/sssf_config.yaml` (missing file is a hard failure); ADW picks any `just adw` recipe; EXTRA appended verbatim (e.g. `--adw-id`); detached via `nohup just --shell bash --shell-arg -c adw <ADW> <prompt> --config <cfg> ... > run.log 2>&1 < /dev/null & echo $!`; pid recorded; run.log truncated per execute.

Gates: pinned HEAD must match intended before the record is written.
15. **observe**: app lane is data-driven — roster `app.path`/`app.manifest`, manifest `serve:` block (default port 4501, health `/`); **no `serve:` block = app lane skipped, not failed**. Trace UI on 4600 from `.claude/skills/sssf/apps/visualizer` against `adws/adw_data/sssf.db`. `ssh exe.dev share port <vm> <port>` + `share set-public`; only ONE port anonymous; obs 307/401 anonymously is correct. App log `~/app-server.log`, visualizer log `~/visualizer.log`.

17. **harvest**: ranged git bundle `<commit_sha>..refs/heads/sbx/<run-id>` → `.sandbox/runs/<id>.bundle` → verify-before-fetch → `refs/sandbox/<run-id>`; target mode fetches into a bare cache `.sandbox/repos/<app-repo-basename>.git` (never into the factory repo); vendored mode fetches into the host repo. Non-destructive, idempotent, safe to run any time. Bundle exists **instead of** a push because the sandbox holds no git credential.
